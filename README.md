## 共享带宽，实际速度能跑到多少

搬瓦工全系共享带宽，但 CN2 GIA 线路的实测速度稳定在 300–500Mbps，晚高峰丢包率接近于零，这是搬瓦工中文社区多年测速反复验证的结果；香港 CN2 GIA 机房实测在 400Mbps 左右。

共享听着吃亏，算笔账就明白了：同样的价格去市场上买独享带宽，一般只能拿到 1–10Mbps。共享池的上限标得高，实际能用多少取决于线路质量和超售程度。

同为 1Gbps 标注，CN2 GT 和 CN2 GIA 的体验差距很大。CN2 GT 在晚高峰会走普通骨干网，拥堵时速度明显下滑；CN2 GIA 是独立通道，与普通流量隔开。社区测评里有个直观对比：晚上八点，GIA 可能还能跑 400Mbps，GT 可能只剩 50Mbps。

延迟方面，洛杉矶 CN2 GIA 机房到国内电信平均约 160ms，三网回程全程走 CN2 GIA 节点；香港更低，广东地区实测 12ms。NodeSeek 论坛有做国内 API 中转的用户评价：香港 CN2 GIA 确实贵，但延迟压到 20ms 以内，目前没有替代方案。V2EX 上也有跑了三年 GIA-E 的用户表示晚高峰从未掉速；搬瓦工中文网的测评结论是“2.5Gbps 是真实的，speedtest 国内节点轻松上 300Mbps”。

香港机房的硬件也说一下。主机测评博客对香港 HKHK_8 机房的测评显示：AMD EPYC 9004 处理器、DDR5 内存、NVMe SSD 阵列，4K 随机读写约 197–198MB/s（IOPS 约 4.9 万），三网回程强制走电信 CTG 接 CN2 链路，晚高峰表现流畅。不过它是广播 IP，实测解不了 TikTok、ChatGPT、Claude、Gemini，Netflix、Disney+、Spotify 可以正常看。冲着大带宽买香港机房的，把这条记下，免得预期错位。
